# Reactorcide web UI

A SolidJS single-page application, compiled into the webapp binary.

- `src/api/transport/` is vendored from `catalystcommunity/csilgen`'s
  `transports/typescript/src/`. Do not edit it here; re-copy it when csilgen's
  transport changes.
- `src/api/csilapi/` is generated by `scripts/generate-csil-ui.sh` from
  `coordinator_api/csil/reactorcide-ui.csil`. Do not edit it.

Build with `./tools build-ui` from the repository root, which writes into
`webapp/internal/embedui/dist/` for `go:embed`.
